# Project images to add

Use real screenshots from your projects. Crop out private customer, student, or account information before publishing. Export screenshots as optimized WebP, JPEG, or PNG files, then put them in this folder and set each matching `src` in `script.js`.

Suggested shots:

- Breathe Easy Solution: homepage, service or booking flow, AC unit listings.
- SneakDup: customer catalog, product stock/sizes/variants, and staff POS, inventory, and sales analytics with business data removed.
- DCSA Mini LMS: student/teacher login, lessons or PDF viewer, quiz creation/taking.
- Data analysis: Excel workbook/dashboard, completed SQL quality checks, findings or charts.
- Networking: final topology, IP addressing/configuration, connectivity tests.
- 2D game: concept/early build and gameplay when available.

Every gallery slot is labeled as pending until its real image path is added. Each project opens in a case study panel, and real gallery images gain an **Open full image** link.

`block-world-concept.svg` is original decorative art for the unfinished 2D game, not a screenshot of the game. Keep the concept label visible until real gameplay images are available.
